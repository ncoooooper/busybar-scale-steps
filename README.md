# Scale Steps

Practise scale degrees in seconds, thirds or fourths and transpose the same exercise into another key.

Wheel steps forward or back through seven scale degrees. Start cycles between seconds, thirds and fourths. Click switches the wheel to transposition; click again to play. Hold the wheel switches major and natural minor. Both displays identify the exercise, degree and sounding octave.

## Run locally

From this folder, run `~/.busy-emulator/bin/busy-emulator dev --once` with BUSY Bar Emulator open. Back exits.
